# VeloDrive 技术栈与依赖安装

## 核心技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 语言 | C++17 | — |
| 构建 | CMake 3.15+ | 编译、链接、测试 |
| HTTP 框架 | wfrest | API Gateway，基于 workflow 的 HTTP 服务 |
| 异步引擎 | workflow | 底层任务调度，MySQL/HTTP/SRPC 任务并行执行 |
| RPC 框架 | sRPC | 微服务间通信，基于 Protobuf |
| 序列化 | Protobuf 3 | 跨进程数据格式 |
| 数据库 | MySQL 8.0 | 用户表 tbl_user、文件表 tbl_file |
| 消息队列 | RabbitMQ | 文件上传后异步备份到 OSS |
| 消息队列客户端 | SimpleAmqpClient | RabbitMQ C++ 客户端 |
| 对象存储 | 阿里云 OSS | 文件云备份 |
| 服务发现 | Consul | 微服务注册、发现、健康检查 |
| Consul 客户端 | ppconsul | Consul HTTP API C++ 客户端 |
| 加密/认证 | OpenSSL + libjwt | 密码哈希(SHA-256) + JWT 令牌 |
| JSON | nlohmann/json | HTTP 请求/响应 JSON 解析 |
| 测试 | Google Test | C++ 单元测试 |

## 第三方库安装

### 1. workflow + wfrest

```bash
# workflow
git clone https://github.com/sogou/workflow.git
cd workflow && mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install

# wfrest
git clone https://github.com/wfrest/wfrest.git
cd wfrest && mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install
```

### 2. sRPC

```bash
git clone https://github.com/sogou/srpc.git
cd srpc && mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install
```

`sRPC` 安装后提供：
- 库文件：`/usr/local/lib/libsrpc.so`、`/usr/local/lib/libsrpc.a`
- 头文件：`/usr/local/include/srpc/`
- 代码生成工具：`srpc_generator`

### 3. Protobuf

```bash
# Ubuntu
sudo apt install protobuf-compiler libprotobuf-dev
```

提供 `protoc` 编译器和 `/usr/local/lib/libprotobuf.so`。

### 4. OpenSSL + libjwt

```bash
sudo apt install libssl-dev libjwt-dev
```

### 5. nlohmann/json

```bash
sudo apt install nlohmann-json3-dev
```

头文件位于 `/usr/include/nlohmann/json.hpp`。

### 6. RabbitMQ + SimpleAmqpClient

**RabbitMQ（Docker）：**

```bash
docker run -d --name rabbit -p 5672:5672 -p 15672:15672 rabbitmq:management
```

**SimpleAmqpClient（从源码编译）：**

```bash
# 依赖
sudo apt install libboost-dev librabbitmq-dev

git clone https://github.com/alanxz/SimpleAmqpClient.git
cd SimpleAmqpClient
mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install
```

库文件：`/usr/local/lib/libSimpleAmqpClient.so`

### 7. 阿里云 OSS C++ SDK

去阿里云控制台创建 RAM 用户并获取 AccessKey，然后安装 SDK。

SDK 编译后会生成 `/usr/local/lib/libalibabacloud-oss-cpp-sdk.a`。

### 8. Consul + ppconsul

**Consul（Docker）：**

```bash
docker run -d --name consul -p 8500:8500 consul agent -server -bootstrap-expect=1 -ui -bind=0.0.0.0 -client=0.0.0.0
```

Web UI：`http://localhost:8500`

**ppconsul（从源码编译）：**

```bash
# 依赖
sudo apt install libboost-dev libcurl4-openssl-dev

git clone https://github.com/oliora/ppconsul.git
cd ppconsul
mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install
```

库文件：`/usr/local/lib/libppconsul.so`

### 9. Google Test

```bash
sudo apt install libgtest-dev
cd /usr/src/gtest
sudo cmake CMakeLists.txt && sudo make
sudo cp lib/*.a /usr/lib
```

## Proto 代码生成

修改 `.proto` 文件后重新生成 C++ 代码：

```bash
cd protos && bash gen.sh
```

生成产物：

| 产出 | 位置 | 说明 |
|------|------|------|
| `auth.pb.h` | `include/` | Protobuf 消息类声明 |
| `auth.pb.cc` | `src/pb/` | Protobuf 序列化实现 |
| `auth.srpc.h` | `srpc/gen/` | RPC Stub / Service 基类 |
| `*.pb_skeleton.cc` | `srpc/auth_service/` | 服务端骨架模板 |

## 依赖关系图

```
server (Gateway)
  ├── wfrest
  │     └── workflow
  ├── sRPC
  │     └── Protobuf
  ├── ppconsul (→ Consul)
  ├── SimpleAmqpClient (→ RabbitMQ)
  ├── OSS C++ SDK
  ├── OpenSSL
  ├── libjwt
  └── nlohmann/json

auth_service / file_service (微服务)
  ├── sRPC
  │     └── Protobuf
  ├── ppconsul (→ Consul)
  ├── workflow (MySQL 任务)
  ├── OpenSSL
  └── libjwt (仅 auth_service)

consumer
  ├── SimpleAmqpClient (→ RabbitMQ)
  └── OSS C++ SDK
```
